APICollector is a Burp Suite extension for API security testing that imports API definitions from OpenAPI (YAML/JSON), Postman, Insomnia, and cURL, maps endpoints and parameters, executes requests, tracks vulnerabilities, and generates assessment reports.

Features

  • Imports API collections from OpenAPI (YAML/JSON), Postman, Insomnia, and cURL to populate an endpoint inventory automatically.
  • Endpoint and parameter tabs provide a structured attack surface map with automatic URL-decoding for human-readable parameter documentation.
  • Built-in request executor allows rapid iteration against endpoints directly within the extension, with an option to send requests to Repeater.
  • Vulnerability tracking supports stateful finding management with Open, Remediated, Verified, and Re-Open statuses, plus side-by-side proof-of-concept and retest evidence.
  • Assessment analytics dashboard displays risk distribution across Critical, High, Medium, Low, and Info severities, along with a remediation progress bar and vulnerable endpoint counts.
  • File-based project management saves and loads entire workspaces as .apic files for assessment isolation and continuity.
  • Report generation exports findings in Markdown, CSV, or JSON formats.

Usage

  1. Open the APICollector tab and use the import function to load an OpenAPI spec, Postman collection, Insomnia export, or cURL command.
  2. Alternatively, right-click any request in Proxy or Repeater and select Send to APICollector to add it to the endpoint inventory.
  3. Review the Endpoints and Parameters tabs to map the full attack surface and data dictionary for the target API.
  4. Select an endpoint and use the internal executor to send requests directly, or forward them to Repeater for further manual testing.
  5. Document identified vulnerabilities in the Endpoints tab, assigning severity and status; findings populate the Vulnerabilities dashboard automatically.
  6. Use the Revalidation Panel to re-test findings, update their status, and capture proof-of-fix snapshots alongside the original proof-of-concept.
  7. Monitor overall assessment health, risk distribution, and remediation progress in the Dashboard tab.
  8. Export the completed assessment as a Markdown, CSV, or JSON report using the report generation function.
  9. Save the workspace via the project management function to produce an .apic file, and reload it later to resume the assessment.
